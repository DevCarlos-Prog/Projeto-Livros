# 📚 Buscador de Livros

Busca livros pela API pública [Open Library](https://openlibrary.org/developers/api).
**Não usa banco de dados, XAMPP nem servidor próprio** — é só HTML, CSS e JavaScript.

## Como usar
Abra o `index.html` no navegador (precisa de internet).

## Como publicar (GitHub Pages)
Repositório → Settings → Pages → Branch `main` / pasta `/ (root)` → Save.
